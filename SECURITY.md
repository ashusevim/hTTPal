# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | yes       |

## Reporting a vulnerability

Please do **not** open a public issue. Email the maintainer listed on the npm profile, or use GitHub's private vulnerability reporting (Security tab → Report a vulnerability).

We aim to respond within 72 hours. HTTPal runs entirely locally: it makes network requests you ask for and stores snapshots/history only on your machine.
